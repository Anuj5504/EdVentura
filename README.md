# EdVentura

A modern Learning Management System (LMS) built with Next.js, MongoDB, and Redis for efficient course management, student tracking, and real-time data caching.

🚀 Features
User Authentication – Secure login/signup system
Course Management – Create, edit, and organize courses
Student Enrollment – Enroll students and track progress
Real-Time Caching – Redis integration for fast data retrieval
Role-Based Access – Admins, instructors, and students
Progress Tracking – Monitor learning analytics
Interactive UI – Built with Next.js for a seamless experience
🛠 Tech Stack
Frontend: Next.js (React Framework)
Backend: API Routes in Next.js
Database: MongoDB (NoSQL for scalable storage)
Caching: Redis (For optimized performance)
